## Boundary layer

- Create a polygon in Geojson.io and export it as a kml file
- Open QGroundControl and select Plan View
- Add home location and pick No Template
- Choose the option, GeoFence, and apply a polygon by importing the kml file
- The default kml file can be found under custom/geofence.
- Save the GeoFence and click on Upload
- Select Fly View
